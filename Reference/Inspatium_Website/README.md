# 인스파티움 웹사이트 — 경영철학·인사말 및 연구원 모집 반영

한국어를 기본으로 하는 정적 HTML 웹사이트입니다. 각 페이지의 `EN` 또는 `한국어` 버튼으로 같은 내용의 다른 언어 페이지로 이동합니다.

## 바로 열기

압축을 푼 뒤 `dist/index.html`을 브라우저에서 여세요. 별도 설치 없이 전체 페이지를 탐색할 수 있습니다. 실제 사이트에 올릴 때는 `dist` 폴더의 내용을 사용합니다.

## 구성

- 홈
- 인스파티움: 비전과 경영철학 / 인사말 / 연구 방향 / 연혁
- 연구: 전체 목록 및 네 개의 개별 연구 페이지
- 논문: 목록 및 논문 소개
- 구성원: 네 명의 소개를 한 페이지에서 전부 확인하는 완결형 카드
- 소식: 연구 소식 / 언론 보도
- 연구원 모집: 함께 연구하며 인스파티움을 기업으로 만들어갈 동료 안내
- 문의

두 언어의 20개 페이지와 기본 진입 페이지를 포함해 총 41개의 HTML 파일을 생성합니다. 소식을 추가하면 해당 소식의 한국어·영어 상세 페이지도 생성됩니다.

기존 개인 소개 주소는 호환을 위해 유지합니다. 구성원 카드 자체는 링크가 아니며, 연구 페이지의 참여자 이름을 누르면 구성원 페이지의 해당 카드로 이동합니다. 사진, 담당 분야, 소개, 관심 분야, 참여 연구, 이메일과 카카오톡 ID를 카드 안에 모두 표시합니다.

## 이번 수정

- 구성원 카드, 개인 소개 페이지, 인사말과 영어 페이지에서 조직 직급을 없애고 담당 분야만 표시합니다.

- 홈 첫 화면의 버튼을 경영철학·인사말로 연결하고, 바로 아래에 두 내용을 나란히 소개합니다. 인사말 요약은 원문의 첫 문장을 사용합니다.
- 연구원 모집은 독립 연구자들이 함께 연구하고 인스파티움을 기업으로 만들어가는 동료 모집으로 소개합니다. 별도 채용 직무, 경력 조건, 보상 조건, 심사 절차는 추가하지 않았습니다.
- 모집 문구는 `content.json`의 `recruitment`에서 한국어·영어로 수정합니다.
- 공통 문의 및 최성준 프로필의 이메일을 `sjchoi@inspatium.co`로 연결했습니다. 모집 페이지의 버튼은 제목이 채워진 이메일 작성창을 엽니다. 사이트에서 메일을 자동 전송하지 않습니다.
- 위치 안내 페이지는 없습니다.
- 오차 보정 연구 항목을 DPU·SoC 기반 피지컬 AI 제어 시스템 연구 계획으로 교체했습니다. 홈, 연구 목록·상세, 연혁에 동일하게 반영하며, 소수 데이터 기반 역설계와 홀로그래피 실험 하드웨어는 유지합니다.

## 내용 수정

`content.json`에 구성원, 연구, 논문, 연혁, 인사말, 비전·미션·철학을 정리했습니다. `build.py`에는 페이지 구조와 나머지 고정 문구가 있습니다.

수정 후 다음 명령으로 HTML을 다시 만듭니다.

```sh
python3 build.py
python3 validate.py
```

Python 표준 라이브러리만 사용합니다. `dist/assets/style.css`는 디자인, `dist/assets/app.js`는 휴대폰 메뉴와 소식 분류 버튼을 담당합니다. 프레임워크나 서버는 필요하지 않습니다.

## 구성원 사진과 연락처

`content.json`의 `people`에서 수정합니다.

| 항목 | 작성 위치 |
| --- | --- |
| 이름 | `name`, `name_en` |
| 담당 분야 | `role`, `role_en` |
| 소개 | `intro`, `intro_en` |
| 사진 | `photo` |
| 이메일 | `email` |
| 카카오톡 ID | `kakao` |

사진을 `dist/assets/` 안에 넣고 `photo`에 그 아래 경로를 입력합니다. 예: `people/sungjun-choi.jpg`. 사진은 현재 이름의 머리글자가 있는 자리를 사용합니다. 이메일을 입력하면 실제 메일 링크가 표시되고, 카카오톡 ID는 텍스트로 표시됩니다. 미입력 상태에서는 잘못된 링크나 전송 버튼을 만들지 않습니다.

역할은 사용자가 제시한 순서대로 최성준: 리드 연구자·기초과학, 김윤채: 수리·과학 AI 엔지니어링, 구윤서: 데이터 과학, 안우진: 하드웨어·장치 엔지니어링으로 배치했습니다. 구성원들의 짧은 소개와 관심 분야는 이 역할을 바탕으로 작성한 검토용 초안입니다. 영문 성명 표기는 본인 확인 후 수정할 수 있습니다.

## 실험 장비 사진

기존 업로드 및 보도자료에서 요청한 실제 하드웨어 사진을 확인하지 못했습니다. 다른 사진으로 대체하지 않았으며, 연혁과 실험 장비 연구 페이지에 작은 사진 자리를 두었습니다.

이미지를 `dist/assets/`에 넣은 뒤 `site.hardware_image`에 그 아래 경로를 입력합니다. 예: `hardware/holography.jpg`. `hardware_caption`과 `hardware_caption_en`으로 설명을 수정할 수 있습니다. 화면 최대 너비는 420px입니다.

## 소식 추가

`news` 배열은 현재 비어 있습니다. 실제 발표 또는 보도 후 아래 구조로 추가합니다. 아래 예시는 설명용이며 사이트에는 게시되어 있지 않습니다.

```json
{
  "id": "unique-news-slug",
  "date": "2026-10-15",
  "category": "media",
  "category_label": "언론 보도",
  "category_label_en": "Media coverage",
  "title": "실제 기사 제목",
  "title_en": "English article title",
  "summary": "기사 소개",
  "summary_en": "Article summary",
  "body": ["본문 첫 문단", "본문 둘째 문단"],
  "body_en": ["First paragraph", "Second paragraph"],
  "url": "https://actual-publisher.example/article",
  "project": "acoustic-optimization",
  "visibility": "draft"
}
```

`category`는 `research` 또는 `media`입니다. 내용을 확인하고 `visibility`를 `public`으로 바꾼 뒤 다시 생성하면 소식 목록, 상세 페이지와 홈의 최근 소식에 반영됩니다. `draft` 항목은 배포 폴더의 HTML에 포함되지 않습니다. 없는 기사나 보도 날짜는 만들지 않았습니다.

## 논문 정보

현재 논문은 '게재 승인'으로 표시했습니다. 공식 논문 제목은 그대로 두고, 한국어 목록에는 한국어 소개 제목을 먼저 표시했습니다. 전체 저자 순서와 실제 논문 링크는 확인 후 `publications`에서 채워야 합니다. 최성준의 문의 메일 외에 다른 구성원의 연락처, DOI, 코드 링크를 임의로 만들지 않았습니다.

`authors`는 실제 저자 순서대로 `{ "name": "이름", "name_en": "Name" }`를 입력합니다. 연구 프로젝트의 참여자 목록과 논문 저자 목록은 서로 구분됩니다.

## 인사말과 경영철학

최성준 리드 연구자의 인사말과 최종 제공된 비전·미션·본립도생 경영철학은 한국어 문구를 보존했습니다. 다른 페이지의 한국어 문구에서는 AI, KISTI와 학술지 고유명 등 필요한 표기를 제외하고 영어를 줄였습니다.

## 검토와 공개

이 버전은 소유자만 볼 수 있는 비공개 검토용 사이트입니다. 2026년 10월 연구 항목과 후속 연구를 포함하되, 후속 연구에 완료 날짜를 만들어 넣지 않았습니다. 색인 방지 설정도 적용했습니다.

기존 개발 안내서에 기록된 논문 공개 일정에 맞춰 공개 전에 논문 상태와 발표 시점을 확인하고, 직접 승인한 뒤 소식 항목을 게시하세요. 공개 사이트로 전환할 때는 `build.py`의 검색 색인 설정과 `robots.txt`도 함께 변경하면 됩니다.
